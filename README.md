# NYKS MEDIA — Official Website

> **Technology. Marketing. Media.**  
> *Build. Market. Broadcast.*

Official modern, responsive web application for **NYKS MEDIA**, a technology and creative media company based in Hyderabad, India.

---

## 🚀 Divisions & Core Offerings

1. **NYKS MEDIA TECHNOLOGY (Web & Mobile Applications)**
   - Business & Corporate Websites
   - Web Applications: ERP, CRM, HRMS, Hospital Management, Fleet Telematics
   - Mobile Apps: Cross-Platform (Flutter / React), iOS, Android
   - Tech Stack: React, Vite, Node.js, Express.js, MongoDB, Python, Flutter, Firebase, REST APIs, Cloudinary

2. **NYKS MEDIA DIGITAL (Digital Marketing & Creative Services)**
   - Meta Advertising (Facebook Ads, Instagram Ads, Lead Generation)
   - Social Media Marketing & Content Strategy
   - Creative Design (Posters, Campaign Creatives, Brand Collateral)
   - Video Marketing (Dynamic Reels, AI-Assisted Videos, Corporate Films)

3. **NYKS MEDIA LIVE (YouTube Live & Event Media)**
   - Multi-Camera YouTube Live Streaming (4K / 60FPS)
   - Blackmagic ATEM Video Switchers & Studio Audio DSP
   - Weddings, Concerts, Corporate Summits, Conferences & Ceremonies
   - Redundant Bonded Multi-SIM Internet Infrastructure

---

## 🛠 Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS with custom dark luxury glassmorphism utilities
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans & Space Grotesk
- **Build Output**: Highly optimized, lightweight production bundle (< 75 kB gzipped)

---

## 💻 Getting Started

### Development
```bash
npm install
npm run dev
```
Open your browser at `http://localhost:5173`.

### Production Build
```bash
npm run build
npm run preview
```
The optimized production bundle is generated in the `dist/` directory.
